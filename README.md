# ЗАБОРЫ РФ

Лендинг компании по установке заборов и ограждений под ключ.

Макет: [Figma](https://www.figma.com/file/aqq6wRfN4sVyfFNZhO5iKa?node-id=0:1&locale=en&type=design)

## Структура

- `index.html` — главная страница
- `styles.css` — стили
- `script.js` — модальное окно, меню, маска телефона
- `assets/` — иконки

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
npx serve .
```

## Секции

1. Hero — заголовок, CTA, статистика
2. Каталог — 6 типов ограждений
3. Почему выбирают нас
4. Как мы работаем (4 шага)
5. Футер с контактами
